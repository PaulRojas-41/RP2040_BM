**Hi, and welcome to explore ARM M0 architecture under the hardware provided by Raspberry pi Pico Board.!**

## **Below there is a brief description of user's environment:** <br/>
  **1. ARM GNU toolchain to compile ARM based CPUs':** <br/>
  [ARM GNU Toolchain](https://developer.arm.com/downloads/-/arm-gnu-toolchain-downloads)<br/>
  **2.Editor of your preference: VSCode is used for this project** <br/>
    **Important:!!** by the moment that we install Raspberry pico PI extension, the mapping for toolchain as well as SDK shall be done<br/>
    either directly in the extension settings or through the file: .vscode/settings.json. This file is automatically filled up by the time we install
    and map the extension. 
    Folder .vscode contains the files that map the environment variables that correspond to <br/>
  **3.CMAKE System Build profile** <br/>
  This is an engine that maps and collects all the toolchain information,targets and sdk libraries to instruct the generator files (Ninja or Makefile) in charge
  to build the final binaries to be load into the board<br/>
  **4.Ninja and Makefile** <br/>
  These are the files that contain the compiler rules to build the final binaries specified in the CMakeLists.txt.<br/>
  **5.Python script to copy UF2 file**</br>
  Allows us put the uf2 file generated by ninja or makefile, into the D: drive that appears at the moment that we connect the board<br/>
  Following steps are recommended: <br/>
    1. Run for the first time in build folder: build> cmake -G "Ninja" .. (or build> cmake -G "MinGW Makefiles" ..)<br/>
    2. Here makefile script or ninja is ready, so we proceed to generate the binaries build>ninja (or make in case we are using makefile)<br/>
    3. Press boot sel and disconnect the cable (here we are doing a mass erase or hw reset)<br/>
    4. Connect it<br/>
    5. Release boot sel button<br/>
    6. D: directory appears <br/>
    7. Execute python script and code is flashed<br/>
