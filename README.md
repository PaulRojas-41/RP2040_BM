**Hi, and welcome to explore ARM M0 architecture under the hardware provided by Raspberry pi Pico Board.!**

## **The following tools are part of the Toolchain:** <br/>
  **1. ARM GNU toolchain to compile ARM based CPUs':** <br/>
  [ARM GNU Toolchain](https://developer.arm.com/downloads/-/arm-gnu-toolchain-downloads)<br/>
  **2.Editor of your preference: VSCode is used for this project** <br/>
    **[Hints]** by the moment that we install Raspberry pico PI extension, the mapping for toolchain as well as SDK shall be done<br/>
    either directly in the extension settings or through the file: .vscode/settings.json. This file is automatically filled up by the time we install
    and map the extension <br/>
  **3.CMAKE System Build profile** <br/>
  This is an engine that maps and collects all the toolchain information to output the generator files (Ninja or Makefile) in charge <br/>
  to build the final binaries <br/>
  **Since GNU is a UNIX Based tool, the Makefile approach for build the project requires the CYGWIN installation:** <br/>
  [CYGWIN](https://www.cygwin.com/). <br/>
  Dont forget to map the corresponding envionment var!!!  <br/>
  **4.Python script to copy UF2 file** <br/>
  Allows us put the uf2 file generated by ninja or makefile, into the D: drive that appears at the moment that we connect the board<br/>
  Following steps are recommended:
    
    Build your project:
    Ninja or makefile command
    Press boot sel and disconnect the cable (here we are doing a mass erase or hw reset)
    Connect it
    Release boot sel button
    D: directory appears 
    Execute python script and code is flashed
